tactical-cz · phase 2 + 3 demo

Phase 2-4 baseline: V-JEPA2-L + BAS head on a Sparta Conference League match

Frozen V-JEPA2-L (Meta, MIT-licensed) encoder, small linear head trained on 4 EFL matches from SoccerNet Ball Action Spotting 2025 (~8K windows, 12 event classes), evaluated on the first 15 minutes of AC Sparta Praha vs Viking Stavanger — UEFA Conference League qualifier, 21 July 2022. Continuous real-broadcast play, Czech commentary, no jump cuts. Out-of-distribution test for the model: different league, different broadcast crew, different stadium.

Phase 1 · Vision
Roboflow sports + ByteTrack
Per-frame player + ball detection, tubelet tracking, pitch homography → coordinates on 120×70 m plane.
Phase 2 · Events
V-JEPA2-L + BAS head
Frozen video encoder + small classifier head, fine-tuned on SoccerNet BAS 2025 (4 EFL matches, 12 classes).
Phase 3 · Audio
Whisper-small (cs)
Czech commentary transcript, keyword-tagged into BAS classes for cross-modal validation.
Phase 4 · Agent
Claude Sonnet 4.6

4 · Ask the pipelineNatural language Q&A (Claude Sonnet 4.6)

The three modalities produce derived parquets — readable, but dense. The agent layer wraps them into a context window for an LLM, which then answers questions in plain language with citations back to the data. Below: five pre-computed questions in Czech and the model's answers. The agent has no access to raw video or audio, only the events / tactical / commentary summaries.

Q1.From the tactical features alone (without watching the video), how is Sparta playing in this 15-min window? Cite specific numbers as evidence.

Sparta's Tactical Picture (Tactical Features Only)

Territorial dominance is clear. The median field tilt sits at 75.0 m on a 120 m pitch — that's well into the opponent's half. Sparta are consistently pushing the action toward the far goal.

Attacking-zone presence is real but not overwhelming. Shot and Cross zone distributions both show 52% of events in the attacking third, which is the highest share of any class. Drive events are 38% attacking-third, Pass 36% — suggesting the build-up is somewhat deeper while the end-product actions (shots, crosses) concentrate high up the pitch.

Shot volume is modest. The Shot class mean probability across all windows is only 0.034, with the peak at 0.716 (t=196.0s). Only a handful of moments crack 0.50+ confidence (t=74.0s: 0.55, t=195–196.0s: 0.68–0.72). This points to sustained territorial pressure but limited finishing situations.

Player density is moderate — mean 8.7 players visible per frame — consistent with a structured, mid-block-pressing style rather than chaotic open play.

Summary: Sparta are dominating territory aggressively, generating crosses and shots in the final third, but converting that positional dominance into clear-cut chances infrequently. A classic high-tilt, low-conversion profile.

Q3.This is the first time the model has seen a Conference League broadcast (training was 4 EFL matches). Does it generalize? What does the calibration on Pass/Drive/Shot tell us?

Generalization & Calibration Assessment

Does it generalize?

Partially, yes — but with clear domain gaps.

Pass and Drive transfer well. Pass achieves mean=0.448 with max=0.952 (t=347s), and commentary agreement rate for Pass-tagged moments is strong: t=150s (0.72), t=156s (0.82), t=161s (0.85), t=689s (0.67). These are bread-and-butter actions EFL and Conference League share structurally — the V-JEPA2 backbone likely generalizes the ball-movement visual pattern.

Drive also agrees at t=323s (0.48 model, commentary confirms breakaway). Cross and Header disagree repeatedly: at t=167s commentary says "centruje" (cross) but model fires Drive(0.34); at t=716s commentary confirms header, model fires Drive(0.84). These aerial/wide actions appear systematically mislabeled — consistent with EFL training data being predominantly central-zone play.

Calibration

  • Pass: well-calibrated at high confidence; mean=0.448 suggests mild overconfidence on non-pass windows.
  • Drive: mean=0.435 is suspiciously high for a less-frequent action — likely bleeds into Cross/Header confusion.
  • Shot: max=0.716 (t=196s) in attacking third is plausible, but two commentary-tagged shots (t=789s, t=873s) score near zero. Recall is the problem, not precision.
  • Goal: max=0.069 — structurally unusable given 16 training examples. Don't trust it.

Bottom line: the model transfers on volume actions (Pass/Drive) but systematically under-detects aerial and wide-play events common in European cup football.

Q4.Coach se ptá: tahle 15-min část zápasu — vidíš v ní něco co model nezachytil dobře? Lidsky, bez ML žargonu.

Jasně, pár věcí mě bije do očí:

Centry a hlavičky jsou podhodnocené. Komentář zmiňuje centry a hlavičkové souboje minimálně 4–5krát (t=167s, t=357s, t=716s, t=741s), ale model na těchto místech vidí hlavně Drive nebo Pass — pravděpodobnosti pro Cross a Header jsou tam pod 0.05. Zkrátka: akce z bočních koridorů model špatně čte.

Standardní situace téměř neexistují. V t=222s komentátor jasně říká „rohový kop" — model v tu chvíli ukáže Out(0.17) a nic víc. Free Kick má přes celý klip maximum jen 0.26. Přitom standardky jsou takticky klíčové a tady jsou v podstatě neviditelné.

„Gól" v komentáři ≠ gól v modelu. Třikrát padne slovo „gol" (t=38s, t=377s, t=475s) — ve všech třech případech model skóruje Goal prakticky nulou. Je ale potřeba říct, že dvě z toho jsou zjevně analytické vsuvky komentátorů, ne živá akce. Model to tedy nutně nechybuje — ale nedokáže rozlišit „mluví se o gólu" vs. „gól padá".

Závěr: Pro rohové kopy, centry a hlavičky bych modelu zatím nevěřil. Na přihrávky a dribling je slušný.

5 · FindingsWhat works, what doesn't, where to look next

Two clear results from running all three layers on this clip. Each survives the smell test independently across modalities.

★ What transfers: continuous-play patterns recognised across leagues

Training was on 4 English Football League matches (2019-2020 season). Inference is on a Conference League qualifier in 2022, different stadium (Stockholm), different broadcast crew, different kit colours, different camera operators. The model nonetheless produces a coherent timeline: Pass + Drive baseline of ~0.45 (correct — football is mostly ball-in-play with passing), Out spikes at ball-out events (max 0.86 / mean 0.12), Shot peaks at 0.72 only at specific moments. This is real cross-domain transfer from the frozen V-JEPA2 features.

P(Shot) along the 900.0-second match window. Sparse, well-localized spikes (mean 0.03) at the specific moments where a shot or shot-adjacent action occurs.

✗ Cross + Header underestimated

The model's Cross-class max P is 0.56 and Header max 0.53, but the commentary explicitly mentions crosses and headers 4-5 times in this window (around t=167s, t=357s, t=716s, t=741s). At those moments the model's top-1 prediction is usually Pass or Drive — the model sees the ball moving and infers passing, missing the specific kinematic signature of a cross or aerial duel.

Cross has 486 training examples in BAS, Header 882 — that's borderline. With more training data per class (Phase 3 LoRA fine-tune or larger annotated corpus), these classes should sharpen substantially.

✗ Goal class still structurally dead (when goals do happen)

This 15-min window has no goals, so the Goal-class staying silent (max P 0.07) is correct behaviour. But the underlying limitation persists: SoccerNet BAS 2025 train split has just 16 Goal annotations across 4 matches (vs 5206 Passes, 5188 Drives). 16 examples is below the floor for the linear head to learn a distinct visual signature — on a clip that DOES contain goals (e.g. the AC Sparta goals compilation we tested before this), Goal collapses into Shot at inference time.

Three plausible fixes for Phase 5+: self-supervised pretraining on the 500 unannotated SoccerNet matches, class-conditional augmentation on the 16 Goal windows (temporal jitter, crop, brightness), or LoRA fine-tune the V-JEPA2 backbone on BAS so the encoder learns the "ball-crosses-line" geometry directly. The last one needs a ~$5 RunPod budget.

✗ Calibration biases on common classes

Beyond Goal, two other classes mis-behave: Out and Ball Player Block fire systematically high across all windows (mean ≈ 0.6, calibration ratio ≈ 0.9 vs 0.1 expected). This is the well-known artefact of multi-label BCE without per-class temperature scaling on imbalanced data. Per-class threshold tuning on validation (see appendix) recovers most of the signal at inference time; proper temperature scaling would fix the logits themselves.

6 · Appendix · ReproduceRun this on your own clip

Full pipeline runs on Apple silicon, no GPU rental. With your own broadcast mp4 and a copy of the trained head:

# 1. Vision: per-frame player + pitch detection
uv run python -m tactical_cz.vision \
    --input data/raw/your_clip.mp4 \
    --out data/processed/vision_tracking.parquet

# 2. Events: V-JEPA2 + BAS head sliding-window inference
uv run python -m tactical_cz.events.infer \
    --source data/raw/your_clip.mp4 \
    --checkpoint checkpoints/head_best.pt \
    --out data/processed/events_timeline.parquet

# 3. Audio: Whisper Czech commentary transcript
uv run python -m tactical_cz.audio.transcribe \
    --source data/raw/your_clip.mp4 \
    --out data/processed/transcript.parquet \
    --model-size small

# 4. Render this page locally
uv run python -m tactical_cz.demo.annotate \
    --source data/raw/your_clip.mp4 \
    --events data/processed/events_timeline.parquet
uv run python -m tactical_cz.demo.render \
    --events data/processed/events_timeline.parquet \
    --annotated outputs/events_annotated.mp4 \
    --vision data/processed/vision_tracking.parquet \
    --transcript data/processed/transcript.parquet \
    --source data/raw/your_clip.mp4
